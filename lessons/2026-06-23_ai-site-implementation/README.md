# AI × WordPress サイト実装デモ講座 第1回

## 概要

2026年6月16日の「AI × WordPress サイト設計デモ講座」で設計したサイトを、AIを使って実際に実装していく講座。

設計済みの要件・ワイヤーフレーム・実装方針をもとに、AIへ指示を出しながらWordPressサイトとして形にしていく過程をリアルタイムでデモンストレーションする。

実装編は全3回程度を予定しており、今回はその第1回。

## 今回の位置づけ

- 前回までに整理した設計内容を実装へ引き継ぐ
- AIを使った実装の進め方と指示の出し方を確認する
- サイトの土台を作り、主要な画面の実装を始める
- 実装中に出てきた課題を整理し、次回以降につなげる

## デモの進め方

1. 前回作成した要件・ワイヤーフレーム・実装方針を確認する
2. 実装する範囲と優先順位を決める
3. AIに指示を出しながらWordPressサイトを実装する
4. ブラウザで動作と見た目を確認し、AIと一緒に修正する
5. 今回の到達点と次回の実装範囲を整理する
