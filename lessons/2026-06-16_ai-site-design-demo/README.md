# AI × WordPress サイト設計デモ講座

## 概要

架空のクライアント要件をもとに、AIと対話しながらWebサイトの具体的な実装設計を進める過程をリアルタイムでデモンストレーションする講座。

要件定義からワイヤーフレーム確認、構成・実装方針の検討まで、実際の案件に近い流れをAIを使って体験できる。

## デモの進め方

1. 架空のクライアント要件を読み込む
2. AIと会話しながらサイト構成・デザイン方針を整理する
3. 実装設計（ページ構成・機能・使用プラグインなど）を具体化する
