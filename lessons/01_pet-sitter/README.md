# ペットシッター・マッチングサイト（講座デモ用・架空案件）

## 背景

ペットを預けたい飼い主と、ペットシッターをつなぐサイトをゼロから作りたい。クラウドソーシングのように決済や仲介まではやらず、両者が直接つながる"きっかけの場"にしたい。

## ① シッターを探す（易）

- 登録シッターの一覧を作りたい
- 対応できる動物（犬・猫・小動物など）や対応エリアで絞り込めるように
- 料金や評価で並べ替えられるように
- シッター個別の詳細ページも用意したい

## ② シッターに問い合わせる（中）

- シッターの連絡先は一覧・詳細に直接出したくない
- 「相談する」ボタン → フォーム経由で連絡してもらいたい
- フォームに飼い主のメール・名前・依頼内容（ペットの種類、預けたい期間など）を入力
- 送信すると対象のシッターに届くようにしたい
- 運営も「誰が誰に相談したか」を把握したい

## ③ 預かり依頼を探す（中）

- 飼い主側が出した「預かってほしい」依頼の一覧を用意したい
- 依頼を条件で検索できるようにしたい
- 一覧 → 依頼詳細に遷移して内容を確認できるように

## ④ 飼い主が依頼を掲載する（難）

- 飼い主が自分で「預かってほしい」依頼を投稿できるように（事前審査なし、ミニマムスタート）
- 依頼には募集期限を設けたい（最短72時間〜最長30日／期限が過ぎたら自動で掲載終了）
- 運営があとから不適切な依頼を非表示にできるように
- 投稿者が自分の依頼を確認・削除できる導線がほしい
