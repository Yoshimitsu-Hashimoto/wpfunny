# 子環境とポートの一覧

新しい子環境を作ったら、必ずこの表に1行追加する。

| ポート | 子ディレクトリ | 用途 | 状態 |
|---|---|---|---|
| 8080 | `demo` | 講座デモ・検証用の枠 | 空き（講座当日に使用） |
| 8081 | — | — | 未使用 |
| 8082 | — | — | 未使用 |

## ルール

- 8080 はデモ・検証専用。案件は 8081 から順に払い出す。
- 使い終わった環境は `scripts/reset.sh` で消し、状態を「空き」に戻す。
- MySQL はホストにポートを公開しない。DB を GUI で見たいときだけ、一時的に
  `3307` 以降を割り当てる（3306 はホストの MySQL と競合しやすい）。
