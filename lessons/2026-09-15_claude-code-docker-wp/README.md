**講座の軸**
> Local は GUI で人が操作する道具。Docker はコマンドで機械が操作する道具。
> だから AI に任せられる範囲が段違いになる。

対象: HTML/CSS 習得済みで WordPress 学習中の方。Docker のメリットは前回（2026-07-21）で説明済み。

## 使う順番

1. `準備手順書.md` の 1〜4 章を上から実行する
2. `parent-template/` を `/Users/yoshio/work/wp-local` にコピーする
3. `準備手順書.md` 5章に従ってリハーサルを2回回す
4. 本番は `デモシナリオ.md` を手元の別ウィンドウに開き、画面共有には `講座テキスト.md` を写す
